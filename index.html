📊 数据集内容

1. 职位列表（jobs.csv）

德国数据工程师职位汇总，含职位名称、公司、地点与链接，覆盖柏林、慕尼黑、斯图加特、杜塞尔多夫及远程岗位。

2. 市场数据（market_data_2026，三种格式同源）

类别内容概要
薪资数据全国平均 / 中位数、柏林·慕尼黑·法兰克福·斯图加特城市对比、数据工程师分级薪资（Junior €45–55k / Mid €60–75k / Senior €75–90k）
签证政策机会卡（Chancenkarte）条件与评分系统、欧盟蓝卡薪资门槛（标准 €50,700 / 紧缺职业 €45,934）
市场需求IT 人才缺口 13 万、AWS 投资与岗位创造、企业数据增长
技能需求核心技能（Python / PySpark / SQL / AWS）与工具栈要求
机会卡评分Chancenkarte 积分制逐项评分标准
城市对比 / 行业趋势主要城市薪资与生活成本、2025–2026 市场走向

🛠 快速上手

import pandas as pd
import json

jobs = pd.read_csv("data/jobs.csv")           # 职位列表
market = pd.read_csv("data/market_data_2026.csv")  # 市场数据（表格）

with open("data/market_data_2026.json", encoding="utf-8") as f:
    data = json.load(f)                       # 市场数据（层级结构）

print(data["salary_data"]["data_engineer"]["salary_range"])
# {'min': 60000, 'max': 90000, 'currency': 'EUR', ...}

  • 程序处理 → JSON（保留层级与中德双语标注）
  • 人工浏览 → Excel
